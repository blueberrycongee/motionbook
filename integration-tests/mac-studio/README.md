# Mac Studio integration regressions

Run `node integration-tests/mac-studio/test-runtime-regressions.cjs` from the repository root with `@napi-rs/canvas` 0.1.100 available. Each example also has its own `npm test`.

This is the 0.1.2 regression harness with directory resolution mapped to descriptive Motionbook slugs. All 323 recorded normal-frame hashes and the original media hashes are retained. All seven normal-speed recreation GIFs and the original MP4 (eight media files) are required and hash-checked, together with 13 historical protected-source records. Six GIFs use [documented lossless re-encodings](qa/gif-encoding-equivalence.json): every composited RGBA frame, delay, loop count, dimension and independent FFmpeg frame/timebase hash matches its original. Their current encoded hashes are checked separately while all eight original hashes remain in the baseline. The parallax GIF is a separate [compressed web preview](qa/parallax-web-preview-compression.json) whose current encoded hash is required. It preserves all 120 frames, per-frame delays and looping, but downscaling and palette reduction change pixels. Its original high-resolution export is retained separately and is not duplicated in this package. The original source-render frame hashes remain exact; they do not imply pixel identity for this compressed preview. The MP4 stays byte-identical. Nine protected files remain byte-identical; four have exact packaging-only substitutions recorded in [packaging-adjustments.json](packaging-adjustments.json). The harness verifies all four packaged hashes. It also reverses the two protected navigation adaptations to recheck their original hashes; the original hashes of the two test-report wording changes remain in the historical baseline. Official reference captures, comparison GIFs and slow-audit exports are not included in the package or its preservation baseline.

The baseline preserves the bundled-media, original protected-source and normal-render hashes from the standalone Mac studies. The adjustment record also covers three navigation-only changes outside the protected-source set. These tests use real Canvas with mocked DOM/events and do not establish live-browser, mobile-device, assistive-technology or performance acceptance.
