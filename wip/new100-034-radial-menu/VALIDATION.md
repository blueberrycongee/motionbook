# Run and validation

Open `index.html`. Hold anywhere inside the dark window and move around that point to select a command. Release or press Escape to close. Commands are demonstrations; they do not trigger browser navigation, printing or saving.

Run `node --test test.cjs`. Five fresh tests cover angular selection, the center dead zone, shortest rotation across the seam, release and repeated opening. They do not establish visual fidelity. Browser runtime has not been executed in this environment. No recorded browser preview or completed native-frame replica audit is claimed.
