# Run and validation

`npm start` serves the interactive demo at `http://localhost:8037`. Move the pointer over the tick field. Arrow keys move a keyboard pointer; Escape leaves the field. Click **Try it**, **Replay reference motion**, or **Reset**; the timeline scrubs native times when the trace is available.

`npm test` runs the live model and clean vector tests. Model tests and offline rendering are not a browser pass. Browser execution and independent final fidelity acceptance remain separate gates.
