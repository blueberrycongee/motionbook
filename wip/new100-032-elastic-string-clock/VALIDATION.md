# Run and validation

Open `index.html` in a browser. Drag the center, either end, or a strand. Release to spring back or snap an end onto an anchor. Press R to reset. The color circles change the background.

Run `node --test test.cjs` for the hub, snap, reset and finite-simulation checks. `test-results.txt` is regenerated for this milestone. These checks validate controller behavior; they do not establish visual fidelity.

Browser runtime has not been executed in this environment. No browser recording or offline animation export is claimed. Static decorative sound and support controls are not wired in this milestone. The final native-frame fidelity review, media decoding and clean-loop checks remain incomplete.
