# Adaptive Precision

[Interactive demo](index.html) · [Source attribution](PROVENANCE.md) · [Current verification](STATUS.md)

Independent vector reconstruction of Rauno Freiberg's calendar event creation interaction: cursor-to-guide morph, downward and upward drags, quarter-hour text quantization, zero-duration crossing, and release fade.

## Run

- `npm test` runs the state and vector-scene tests.
- `npm start` serves the demo at `http://localhost:8035`.
- Open the demo, choose **Try it**, and drag within the calendar. Space starts/releases a keyboard drag; arrow keys move by 15 minutes; Escape cancels.

This is a recoverable WIP checkpoint. The native replay trace, clean media and independent fidelity review are pending. Browser runtime is unverified, with the actual startup limitation recorded in STATUS.md. It is not an accepted new-100 case.
