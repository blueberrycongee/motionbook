# Reference

Customizable glass folder by @shedsgns: [original post](https://x.com/shedsgns/status/2101668953567199247), [Inspora](https://www.inspora.design/posts/folder-interaction).

A menu creates a glass folder; its paper lifts, color swatches appear, the name changes, and a heart draws then erases in reverse. Reuse `scene.js` for the vector glass and `native-data.js` for scale, palette, hue and stroke-length tracks.

The reference stops on the renamed folder. The demo adds a return to the menu at 10.95–11.55 seconds and holds through a 12-second loop. See [RIGHTS.md](RIGHTS.md).
