# Source and independent reconstruction

- Observed source: [File upload card on Inspora](https://www.inspora.design/posts/file-upload-card)
- Credited creator: [@dawoodui on X](https://x.com/dawoodui/status/1969430346845340148)
- Original media: [MP4](https://media.inspora.design/posts/ae36ffce-c247-416b-897e-5dfa26282169.mp4), verified against the original-media field rather than the gallery preview
- Original file SHA-256: `21f1a9d1bc6021f4d40a118c57bc08e8b5c38ce58b4d3d70f506fb9fadbbcd47`
- Observed 2026-10-05. The original is 1080 × 1080, 223 encoded frames at 60 fps, 3.716667 seconds. All 223 original frames, with native timestamps 0–3.7 seconds, were inspected in chronological motion-region sheets and detailed crops.

The reference shows a dark upload card, a folder opening in perspective, a dragged PDF capsule dropping behind its front, and delayed light spreading through the folder before it settles closed.

The implementation is independently authored SVG paths, masks, analytic gradients and JavaScript. Folder outlines, paper glyph and pointer were drawn for this study. Scalar pose, cursor and three lighting envelopes were measured from the source at each native frame. The document drop angle was refined from its visible top edge. No source frames, image textures, footage, proprietary code or extracted design assets are embedded in the demo or previews. System-font substitution is used; no proprietary font is bundled.

The 4-second preview preserves the full original sequence and adds a brief neutral settling tail. Local picker/drop behavior, replay and reduced-motion handling are authored demo behavior, since the source is footage rather than a publicly testable application. Selecting a file displays only its name. No file contents are read or uploaded.
