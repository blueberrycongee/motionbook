- Original presentation: 1506 × 1502, 1,031 frames, 17.2 seconds, PTS 0–17.183333. One nominal 60 fps sample is absent; `motion-data.js` retains the actual PTS.

The original was retrieved through the normally playing public browser video using its documented download operation. All 1,031 original frames were visually inspected on 2026-10-06. Additional enlarged checks covered the lighting, chrome switch, tooltip and reverse windows.

`scene.js` is an independent SVG reconstruction. The light field is generated by `make-light-field.py` from analytic Gaussian profiles, without reading reference images. `motion-data.js` contains measured scalar positions, light levels, four traveling border intervals and fitted caption/switch phases. It contains no image samples. The arrow and feather are independently drawn paths.

The reference shows repeated hover lighting, a lifted panel, the switch changing to On, and the switch resetting to Off when the pointer leaves. A 1.8-second authored tail closes the 19-second demonstration. The tail is not part of the reference recording.
