# Reference

[Light Work on Inspora](https://www.inspora.design/posts/6-1) · [Original post by @Designownow_](https://x.com/Designownow_/status/1921052041520041991)

Hover lights and lifts the panel; the chrome switch turns On, then resets when the pointer leaves. `scene.js` draws the interface, `make-light-field.py` generates Gaussian lighting without source images, and `motion-data.js` stores light, border, caption and switch tracks at native timestamps.

The 19-second replay adds a 1.8-second cursor-return tail. See [RIGHTS.md](RIGHTS.md).
