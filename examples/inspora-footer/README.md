# Inspora footer

[![Inspora footer](delivery/footer-preview.gif)](delivery/footer-preview.mp4)

[Demo](index.html) · [Video](delivery/footer-preview.mp4) · [Horse detail](delivery/horse-detail.mp4) · [Source & rights](PROVENANCE.md) · [License](LICENSE.txt)

An illustrated footer with procedural scenery and a walking horse. Reuse `horse-motion.js` for the pose model.

- Tests: `node test.mjs` and `node test-motion.mjs`
- Artwork: `node scripts/draw-desert.mjs`
- Preview: `npm install`, `node scripts/render-preview.mjs`, then `bash scripts/encode-previews.sh` (FFmpeg required)
