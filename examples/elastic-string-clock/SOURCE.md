# Reference

[Watchface on Inspora](https://www.inspora.design/posts/1-39) · [Original post by @itshassco](https://x.com/itshassco/status/2091467742209552818)

Strings attach to a clock hub. The hub springs home after dragging; free tips fall or snap to new anchors, and plucks send waves along strands. Replay changes the black strand to the seconds anchor and the red strand to the hour anchor.

`scene.js` draws vector bands; `physics.js` provides the interactive Verlet model. The replay preserves native timestamps and adds an authored return after 17 seconds for a 20-second loop. No source pixels are bundled; see [RIGHTS.md](RIGHTS.md).
