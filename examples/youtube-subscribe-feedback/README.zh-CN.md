## 这次实际改了什么

- 白色胶囊逐渐变成深色底，出现内嵌红—品红边框；不再循环彩虹扫边
- 激活后短暂从白 / 粉过渡到红—品红填充，再变成深色
- 视觉文案延后切换为 Subscribed；本地逻辑状态在激活时立即提交，不等待动效
- 四角星、圆点及圆点散开的细点改为红 / 粉色系，并重新匹配位置和节奏
- 胶囊右端固定，明显收窄；文字淡出、铃铛和下拉箭头出现
- 新增衰减式铃铛摆动，再静止

## 帧级观察与实现映射

官方原片：1920×1080、30 fps、240 帧、8 秒；组件约每 4 秒复演一次。下列 PTS 都指第一轮原片时间，观察精度约为 1/30 秒。

| 原片轨道 / 时间 | 观察 | 独立实现 |
|---|---|---|
| 提示约 0.567–0.900 s | 白底变深、边框显现 | 深浅填色与标签颜色同步渐变 |
| 提示约 0.900–2.100 s | 红—品红边框保持 | 斜向品牌渐变，不额外添加外发光 |
| 提示约 2.100–2.433 s | 边框退去、回到白底 | 对称结束过渡 |
| 奖励约 0.833–1.000 s | 粉色从左侧推进到红 / 品红 | 分段色标近似横向填充 |
| 奖励约 1.067 s | 文案变成 Subscribed、星点出现 | 视觉标签延后约 0.267 秒 |
| 奖励约 1.400–1.900 s | 深色背景，星点消散 | 固定布局、确定性时序与细点 |
| 奖励约 1.967–2.200 s | 文字淡出、胶囊收窄、铃铛出现 | 右侧锚定，126 → 79 设计像素 |
| 奖励约 2.200–3.050 s | 铃铛摆动后稳定 | 取样关键帧插值，结束后角度归零 |

这些是从官方演示测出的视觉近似，不是 YouTube 源码中的设计常量。参考经过视频压缩和 GIF 量化，字体、像素边缘、粒子轮廓与原产品可能不同。

## 本地运行

需要 Node.js 20 或更新版本。

```sh
cd examples/youtube-subscribe-feedback
npm start
```

在浏览器打开 `http://127.0.0.1:4177`。网页本身不需要安装依赖，不请求外部资源。

- Replay demo：重播，取消上一轮所有状态
- Reset：回到初始状态并取消自动提示与点击
- Simulate spoken cue：模拟内容提示；不自动订阅
- Reduced motion：静态提示边框；激活后直接显示稳定确认状态，无填色动画、星点或铃铛摆动
- Tab / Enter / Space 使用原生按钮语义；页面空白处 R 重播、Escape 重置
- 连续快速点击只接受第一次有效激活；已订阅态点击无额外副作用
