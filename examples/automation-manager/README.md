# Automation manager

![Automation manager](preview/native-automation-workflow.gif)

[Demo](index.html) · [Video](preview/native-automation-workflow-60fps.mp4) · [Source and assets](PROVENANCE.md) · [Run and scope](VALIDATION.md)

An independent reconstruction of the ChatGPT automation interface and its local client-state behaviour. It simulates task management locally: it does not create real ChatGPT tasks or execute AI requests.

This is an interface study rather than a measured motion reconstruction, so it carries no native reference frame counts. The regular/inset layout is an explicit study preset; the compact/team variant is not inferred, and native app execution and real browser layout are untested.

The regular layout, local interactions and preview media are complete. Independent review has not been run.
