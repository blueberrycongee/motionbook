# Behavior and validation

Three Update → Updating → Cancel cycles combine an attached circular cancel control, spring overshoot, blue progress fill and pointer movement. The interactive demo adds simulated completion.

Tests cover repeated clicks, cancel/restart, Escape, focus, reduced motion, completion, finite scenes and native-time replay. Previews share the SVG scene but render offline; actual browser behavior remains unverified. Nunito typography, shading and cursor contours approximate the reference.
