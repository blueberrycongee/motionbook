# Run

Open `deliverables/interactive.html`, or run `npm start` and open port 4187. Click Update; × or Escape cancels. Keyboard and reduced-motion controls are included. Updates are simulated locally; an eight-second completion reset prevents an indefinite busy state.

Reuse `src/motion.mjs` for progress/cancel motion and `src/scene.mjs` for SVG drawing.

- Test: `npm test`
- Render: `npm install && npm run render` (FFmpeg required)

See [REVIEW.md](REVIEW.md) for verification limits.
