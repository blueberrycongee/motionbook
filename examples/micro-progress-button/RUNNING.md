# Run

Open `deliverables/interactive.html` directly for the self-contained demo, or run `npm start` and open port 4187. Click Update; cancel with × or Escape. Keyboard and reduced-motion support are included.

Run `npm test` for the model and wiring checks. `npm run render` requires the declared Sharp dependency and FFmpeg. Browser execution remains unverified; see REVIEW.md.

The accepted M02 source and media are unchanged. Publication only reorganizes the README/run documentation and retains the accepted manifest under evidence/.
