## Motion observation

All three groups and all nine leaf selections belong to one distinct motion. The primary marker recolors before translating. Child groups fade and clip at fixed text scale while later headers move; changes in total height also recenter the whole sidebar. The colored branch bends continuously between selected rows. Font weight changes at selection start while text and icon colors continue easing. The pointer is a separate moving layer with a press scale and soft shadow.

The 615 original frame states are evaluated at the original PTS and encoded in their original order at 60 fps. The added 39-frame tail returns the pointer and small residual values to the first state and holds for a clean loop. The tail is independently authored and is not part of the original recording.
