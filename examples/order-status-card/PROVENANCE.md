Reference: [Order Status Card](https://www.inspora.design/posts/order-status-card), credited to [@zahragr8r](https://x.com/zahragr8r/status/2104058418223034382).

Original public footage: https://media.inspora.design/posts/d544d068-4dfc-4bb0-9c0b-a88813a32880.mp4. The audited file is 2880 × 2160, 305 native decoded frames at 60 fps, 5.083333 seconds. SHA-256: `a8417d5577a052247cc763e645d01005f78cbe54d8eaab35f1b680a936cf810f`. Analysis used the original frames and native presentation timestamps, not a reduced-rate preview.

No redistribution license for the reference footage was established. No original footage, screenshots, image fragments or source texture pixels are included. The panel, paw mark, cooking pot, parcel, bicycle, delivery hand, badge and progress segments are independently drawn SVG geometry. The paper grain is independently generated from a seeded texture function. These assets are not extracted from source frames. Source attribution does not imply endorsement or rights in the creator’s design.

`motion-data.js` contains scalar appearance measurements and fitted timing: panel and logo bounds, staggered line opacity/offsets, track appearance, badge centers/radii and native timestamps. They are not original application code or recovered CSS. Video compression and threshold sensitivity limit measurement precision. The source starts mid-delivery and ends with the fourth segment complete; a short independently authored re-arm tail restores the initial badge/segment state for a seamless loop.

Liberation Sans Regular is an unmodified installed font from `/usr/share/fonts/truetype/liberation/LiberationSans-Regular.ttf`, used as a licensed substitute because the original font was not established. Its existing SIL Open Font License and upstream notices are preserved in `assets/Liberation-LICENSE.txt`. Project: https://github.com/liberationfonts/liberation-fonts. Per-line optical transforms fit observed text dimensions without copying source glyph pixels.
