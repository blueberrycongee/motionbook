# Validation

## Verified

- 67 automated tests: 32 motion, 28 simulated DOM/static adapter, 7 media/encoder checks
- Shared SVG scene renders through Sharp/librsvg without XML errors; persistent browser nodes are patched rather than replaced every frame
- Source coordinates: 432×934, at fixed original crop (744,74)
- 145 measured geometry rows evaluated at original PTS; all rows remain present in comparison diagnostics
- 161-frame normal-speed media export: 30000/1001 fps, 5.372033 seconds. GIF uses integer centiseconds, 5.37 seconds total, approximately −2.03 ms total quantization error
- 12 paired source/reconstruction landmarks and an all-frame geometry/RGB residual report
- Each media manifest preserves the historical render-input and output hashes; its maintenance evidence separately binds current runtime revisions to the unchanged reference SVG sequence and media bytes
- Normal GIF and MP4 are generated by the same SVG state/scene used in the runtime, not a separate imitation drawing
- Cross-mode handoff preserves every current layer at takeover and uses a bounded supplemental settling correction
- Repeated input, direction reversals, drag cancellation, keyboard/assistive click, reduced motion, hidden-page and bfcache clocks, idle RAF stopping, and input-velocity independence from RAF cadence

## Explicitly not verified

- Browser runtime appearance, actual DOM layout and device GPU/frame latency. Browser localhost navigation was not used after the earlier environment security block; it was not bypassed
- Native iPhone touch behavior, finger velocity, release thresholds, arbitrary canceled gestures, native Apple spring constants or 120 Hz equivalence
- Pixel-perfect font, artwork, icon, background-material or continuous-corner equivalence

The automated adapter uses a simulated DOM and the offline export uses librsvg. Neither is a browser screen recording or performance benchmark.

## Reproduce

```sh
npm install
TEST_MEDIA_ENCODER=1 npm test
npm run render
node tools/evaluate-withheld.cjs
```

Optional critical source comparison, with a separately authorized source video kept outside the repository:

```sh
node tools/build-comparison.cjs \
  --source /absolute/path/to/official-video.mp4 \
  --measurements validation/observations.json \
  --holdout-report validation/holdout-geometry.json \
  --withheld-model validation/withheld-calibration-data.json \
  --out /absolute/path/outside-repository
```

Geometry observations and color tokens may be reused without distributing the source footage. The final all-point fit must not be described as independent held-out accuracy. See FIDELITY.md for historical held-out results and uncertainties.

`preview/render-manifest.json` retains its original `core` rendering provenance. Its `runtimeMaintenance` entry points to `validation/runtime-maintenance.json`, which records the historical and current source hashes, the changed adapter hash, all 161 pre-maintenance reference SVG hashes and the preserved output hashes.
