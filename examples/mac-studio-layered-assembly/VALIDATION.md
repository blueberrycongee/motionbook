# Validation boundaries

Version 0.1.2 preserves the original deterministic reference animation while fixing targeted runtime edge cases. The [collection regression harness](../../integration-tests/mac-studio/README.md) checks 323 normal-render frame hashes, eight bundled recreation media files and 13 original protected-source hashes. Four protected HTML/test files have documented packaging-only substitutions: navigation destinations or the browser-QA report wording. The harness checks the exact final hashes of all four files and reverses the navigation substitutions to recheck their original hashes. The original test-file hashes remain in the historical baseline; the other nine protected files remain byte-identical. Official reference captures, side-by-side comparison GIFs and slow-audit exports are excluded.

`npm test` runs this example's real-Canvas/DOM-mock `test.cjs`. This is deterministic offline runtime testing, not live-browser, real mobile-device, assistive-technology or performance acceptance. See the README for the specific controls and checks. The aggregate regression harness additionally exercises interrupted tabs, resize behavior and mapped preservation evidence where relevant.

Animation source, reference timing and original artwork are unchanged. Six GIFs use [documented lossless encodings](../../integration-tests/mac-studio/qa/gif-encoding-equivalence.json) with identical decoded frames, delays, dimensions and looping. The parallax GIF is a separate [compressed web preview](../../integration-tests/mac-studio/qa/parallax-web-preview-compression.json): all 120 frames and their timing are retained, while downscaling and palette reduction change pixels. Its original high-resolution export is retained separately and is not duplicated in this package. The MP4 retains its original bytes. Bundled file bytes can be verified against `FILES.sha256`. Run the example and aggregate tests to verify the current checkout; the included historical results describe offline checks only.
