# Validation

See [RUNNING.md](RUNNING.md) for demo and test commands.

Tests cover local state, simulated event handlers, canceled/stale completion, selection reversal, search ranking, header/width independence, tag-to-dots ordering, finite scenes and loop endpoints.

Previews render offline from the shared Canvas scene. Actual browser layout, accessibility, pointer handling and performance remain unverified; font rasterization can differ and the recording cursor is omitted.
