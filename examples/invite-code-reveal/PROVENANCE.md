- Observed reference: [Invite code interaction on Inspora](https://www.inspora.design/posts/invite-code-interaction)
- Credited creator: [@nitishkmrk on X](https://x.com/nitishkmrk/status/2103061978680086905)

- Original file SHA-256: `ee0d2f26c91ed1659d9511a7778cc9aabb65bcb58fc2e387c181b8ae1d6dae4d`
- Observed 2026-10-05. The original-media field was verified rather than using the gallery preview. The file is 960 × 960, 383 encoded VFR frames, 6.6723 seconds, with native timestamps from 0 through 6.655567 seconds.

The source shows three complete hinged-lid opening, spring recoil and closing cycles. The front reads “Your Invite Is Ready”; the back reads “Your Invite Code”. A dotted capsule beneath contains “LoveSwiftUI” and a green Copy button. The original footage does not demonstrate the Copy action.

## Authored implementation

Capsule geometry, its projective mapping, white rims, dotted border, arrow, pointer and shadows were drawn and coded for this study. The lid is a projected vector plane: its contour and each typographic outline are transformed with the same projective denominator, including the thin edge-on frames. Scalar pose and pointer controls were measured at the original 383 timestamps. Short near-edge-on states were refined from visible green-circle centroids rather than guessed solely between distant keyframes.

No reference frames, textures, footage, proprietary font or extracted source design files are embedded. The source is not played in the demo. The 7.2-second authored loop includes all three source cycles and a short neutral tail. Live toggling, interrupted/reversed motion, clipboard feedback, replay and reduced-motion behavior are authored controls rather than claims about a tested original application.
