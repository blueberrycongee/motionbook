# Reference and motion

Reference by [@jeetnirnejak](https://x.com/jeetnirnejak/status/2095507715556831429). [Inspora](https://www.inspora.design/posts/rag-pipeline) · [Original footage](https://media.inspora.design/posts/853f7be4-b028-40dd-9a3f-35036e0ffd6d.mp4).

The interface resets a completed answer, then runs Query, Embed, Retrieve, Assemble and Generate. Pulses connect the stages; an embedding barcode fills, scored documents appear with staggered bars, and prompt segments fill in order. The panel expands while word groups fade into the answer. Each citation sends a halo to its ranked source. Timer, completion badges and active icons have separate schedules.

The demo uses one complete run, including initial hold, reset, all stages, response and final hold. The reference's repeated second run is omitted.

`native-data.js`, `embed-data.js` and the handoff/footer-dot tracks hold measured scalar positions, colors, timing and opacity. SVG geometry, layout and code are independently authored; the answer is independently worded. See [rights](RIGHTS.md).
