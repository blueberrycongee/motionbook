# Source and rights

Reference: [Luminous tabs on Inspora](https://www.inspora.design/posts/9-6), posted by [@marcelkargul](https://x.com/marcelkargul/status/2089632076370763821).

Tab geometry, icons and lighting are independently authored. Light uses two Gaussian fields below each tab, an exponential vertical reflection with a generalized Gaussian horizontal mask, and a narrow specular stripe. No original code, font, footage or source pixels are embedded.
