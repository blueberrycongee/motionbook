# Source and rights

Reference: [Graph Slider](https://rauno.me/craft/graph-slider), by [Rauno Freiberg](https://x.com/raunofreiberg), published May 2023. The author credits Family's iOS app for the idea and Siddhartha for the graph. The implementation here redraws the geometry and interface independently.

The original [reference footage](https://cdn.rauno.me/graph-slider-2.mp4) has 552 native frames at 1340 × 836, spanning 9.2 seconds. SHA-256: e186b7ec5a0ce1c97af064720c7e548060e6fa7443fcd6cb73c5f26f5ff2a27a. Reference footage and local comparison crops are excluded from the implementation package.

The graph path, marker, guide, gradients, tooltip and pointer are independently authored SVG geometry. The public author explanation informs the interaction: pointer movement maps to distance along the curve, while the tooltip keeps a fixed vertical position. No original source code or image asset is embedded.
