# Source and assets

Reference: [Ringwriter on Inspora](https://www.inspora.design/posts/1-60), by [@edo_lunardi](https://x.com/edo_lunardi/status/2079129478630977948). [Author's lab](https://www.edoardolunardi.dev/lab/ringwriter) · [Original footage](https://media.inspora.design/posts/6d134bd8-7e48-4cba-bcd7-7d29b9357b9b.mp4).

The scene draws dots, licensed glyph outlines and a vector cursor independently. Motion tracks contain ring radii/phases, character identities, scale, opacity and letter offsets. They include no source pixels or copied implementation. The font derivative, Replica Ring Mono, retains its upstream attribution and SIL Open Font License in `licenses/`. The original typeface is unidentified.

The replay includes outward reveal, enlarged wave-front letters, independent letter movement during the hold, contraction, release wave and pointer/label movement. An authored fade returns the replay to its starting background. Live hover, hold/release, cancellation and keyboard input extend the observed interaction.

Reference footage and analysis crops are not redistributed. No redistribution rights for the original design or footage are asserted.
