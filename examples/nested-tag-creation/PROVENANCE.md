# Source and rights

Motion reference: [Nested tag creation on Inspora](https://www.inspora.design/posts/1-54), by [@dejvdesign](https://x.com/dejvdesign/status/2092547295950618961). The original footage is used locally for visual analysis and is not redistributed.

Original source SHA-256: 078a14234f97fc31aa7855d93b32d13ecaf5b4151b7c7d30d52d378ea873c7b1. It has 1,022 variable-rate frames at 1200 × 1248, spanning 22.035 seconds. The implementation preserves its actual presentation timestamps. A final return-to-start segment is independently authored for looping.

The SVG artwork and implementation are independently authored. No blanket license is granted for this implementation, and no rights in the reference artwork or footage are claimed.

Inter Regular and Medium are licensed under the SIL Open Font License in assets/Inter-LICENSE.txt. These font bytes were recovered from the previously published flight-pill package and verified against its Git object hashes. The upstream project is [Inter](https://github.com/rsms/inter). A matching version-4.001 variable source and OFL were separately downloaded from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter) during recovery; they are retained outside this package as local research inputs.
