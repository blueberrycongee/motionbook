# Source and rights

Reference: [File toss on Inspora](https://www.inspora.design/posts/7-6), from [@nilseller](https://x.com/nilseller/status/2077423947004641474).

The original has 282 native frames at 30 fps, 1920 × 1360, spanning 9.4 seconds. Source SHA-256: 218c90d0dd3d9510e3a5d2609fe4518c3a5b7d6e2c3ed09413cb5594260a6cce. Reference footage and image crops remain outside the package and are not redistributed.

The cylindrical bin, faceted paper, document icon, cursors and interface are independently drawn SVG artwork. Interactive tossing, keyboard deletion, Undo and the final return-to-start segment are independently authored behavior. The source shows the Undo control but does not show it being used.

The bundled Inter fonts come from the [Inter project](https://github.com/rsms/inter); the SIL Open Font License is in assets/Inter-LICENSE.txt. No blanket license grant is made for the new implementation, and no rights in the reference media are claimed.
