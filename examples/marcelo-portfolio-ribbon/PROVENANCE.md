# Provenance

Reference: https://x.com/MarceloDesignX/status/2107307188343742937

Retrieved 2026-10-06 through official public X syndication, then the exact official 3024×1964 MP4 URL provided in the response. Both requests returned HTTP 200; no login or changed client identity was used.

The source video stream contains 679 native frames over 11.75 seconds (variable frame rate). All 679 frames were extracted, reviewed across 11 consecutively numbered contact sheets, with selected full-resolution frames inspected separately. Original frames and media are local analysis-only and must not be published or embedded in the implementation.

Five original images were generated with the built-in image generation tool, without any reference image supplied: three fictional adult portraits, a cobalt glass sphere, and a brushed-metal kinetic sculpture. Source poster artwork is recreated independently with original vector drawing/code and freely available fonts. No original image, cropped texture, screenshot, sound, or source pixel is embedded in the delivered UI or preview.

This is an independent private study of the interaction, not a claim to ownership of the referenced design. Offline renders will share the implementation's geometry and textures; browser playback has not been tested because local browser preview is blocked.

## Fonts and generated artwork

- StudySans.ttf is the installed open-source Liberation Sans Regular, with its license included as StudySans-LICENSE.txt. It is used for recreated lettering and interface chrome.
- StudyCJK.otf is a two-character subset (余白) of the installed Noto Sans CJK Regular; its SIL Open Font License information is included as StudyCJK-LICENSE.txt. It is used only in the independently composed cream poster.
- The complete image-generation prompts are recorded in assets/generation-prompts.json. Built-in image generation was used; no user API key or external paid API was required. No reference images were passed to generation.
- Original generated PNG masters remain local. The portable project contains compressed JPG derivatives of those new assets, the five generated poster PNGs, fonts, original drawing code, and numeric geometry/timing only.

The recorded source audio is not used.
