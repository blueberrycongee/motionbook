# Run

Run `npm start` and open `http://127.0.0.1:4189`. Drag or scroll to browse; arrows move, Space pauses/replays, and Escape/Home restarts. Reduced motion disables autoplay and momentum.

Reuse `src/geometry.mjs` for the inverse screen-space mesh, `src/motion.mjs` for drag/inertia and `src/scene.mjs` for drawing.

- Test: `npm test`
- Preview: `npm install && npm run render`
- Posters: `npm run assets`

See [REVIEW.md](REVIEW.md) for checks and [PROVENANCE.md](PROVENANCE.md) for artwork/fonts.
