# Curved portfolio ribbon

Independent, preview-first reconstruction of the [referenced interaction](https://x.com/MarceloDesignX/status/2107307188343742937). Accepted for publication; the implementation and review limits are retained.

## Run

Run `npm start`, then open http://127.0.0.1:4189. The browser demo has no runtime dependencies or network requests.

Drag or scroll to browse. Arrow keys move; Space pauses/replays the demonstration; Escape or Home restarts. Reduced-motion preferences disable automatic playback and momentum.

`npm test` runs the geometry, timing, controller and mocked event-binding checks. `npm install && npm run render` regenerates the offline MP4 and GIF. `npm run assets` rebuilds the five original typographic posters.

## Preview

The MP4 follows all 679 native timestamps over approximately 11.75 seconds. The GIF is a clean 30 fps preview. Both are offline canvas renders from the same geometry and asset code used by the interactive demo. They are not browser recordings.

Five images were newly generated; five posters were drawn independently. No original reference image, cropped texture, video or audio is included. See PROVENANCE.md and REVIEW.md.
