# 还原范围与差异

四组歌词依次启动，组间约差 1–2 个源帧；向上移动约 203 个源裁切像素，部分组有约 4px 越界回落。Incoming 组内部各行相对展开约 3–4px，因此保留独立行轨迹。以 ±2px 收敛带计，主要组约在启动后 0.73–0.80 秒稳定；被页头遮住的路径不补造观测。

行内高亮采用实测柔边亮度场，分开控制前沿、羽化宽度与起步亮度，保留真实变速和后段停顿。文字仅绘制一次，并按 Inter 实际墨迹边界显式横向缩放。详见 [量测方法](validation/highlight-measurement-method.md) 与 [映射规则](validation/highlight-mapping-diagnosis.md)。

字体、文案、封面与静态背景为替代/原创内容。位置量测是模板框位移；模糊与对比增益是图像拟合，不能视为 Apple 的字体基线、alpha、blur 或 spring 常数。没有原始 TTML 或音频时钟，不声称逐词音画同步。

最终轨迹使用全部有效观测点；同点拟合残差不能充当独立准确率。手动查看、反向、取消、0.45 秒恢复跟随和减少动态效果是补充交互。浏览器、原生设备及 60/120Hz 性能未验证；检查范围见 [VALIDATION.md](VALIDATION.md)。
