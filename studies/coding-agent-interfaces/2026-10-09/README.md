## 最有价值的差异

1. **Conductor：固定位置承载不同尺度。** 左侧管理并行任务，中间保留对话，右侧集中审阅与运行。工具输出先摘要，再进入细节。
2. **Claude：输入意图有明确边界。** 文档区分建议采纳、发送、运行中排队补充和立即停止；适合做独立的输入状态机案例。
3. **会话切换：状态属于会话，而非当前画面。** 草稿、阅读位置、活动结果和未提交评审意见应有稳定归属。这是建议的复刻原则，尚未运行验证。

## 证据规则

- **观察**：官方截图实际可见的结构，或已下载文件的字节数与哈希。
- **文档事实**：官方说明的功能，不保证与某个下载构建完全一致。
- **原创建议**：从上述信息推导的独立实现与验收要求，不能冒充原产品行为。

本批没有测量动画时长、缓动、弹簧参数、CSS token、字体或响应式断点；没有安装、启动或登录这些应用。官网实现不等于桌面应用实现。文件哈希不等于厂商签名验证。
