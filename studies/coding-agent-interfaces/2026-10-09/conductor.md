## 从画面直接看到什么

| 区域 | 观察 | 可借鉴的设计意图（推导） |
|---|---|---|
| 左侧索引 | Home / Create / Search 在上；Pinned、My workspaces、Team 分段；长标题截断，部分行保留时间或头像；浅底标明选中项 | 导航位置稳定，支持同时扫视多个任务 |
| 中间对话 | 顶部活动标签有细下划线；用户消息浅底，助手正文直接呈现；工具调用折为摘要，文件变更另有小标签 | 日志可达，正文仍能快速阅读 |
| 底部输入 | 圆角浅底容器承载多行输入、人物提及、聚焦提示和模型／effort 信息；发送按钮在右下角以深色突出 | 输入、上下文和发送保持同一视觉归属 |
| 右侧审阅 | PR 状态与 Merge 相邻；All files / Changes / Checks / Review 分层；文件名与增删数突出；下方另有 Run / Terminal | 将“是否准备好”和“下一步动作”放近 |

浅灰层级、细分隔线和局部高对比构成主要视觉语法。部分任务旁可见细绿标识，但仅凭截图无法确定其状态语义。这里没有声称准确色值、圆角、字体、面板宽度或动画参数。

## 导航：Command palette 与 Spotlight 不同

[官方快捷键文档](https://www.conductor.build/docs/reference/keyboard-shortcuts)将 ⌘K 称为 **Command palette**。⌘P 快速打开文件，⌘L 聚焦聊天输入；文档还列出独立切换边栏／终端、前进／后退、重开标签、切换工作区及跳到需关注聊天的操作。

[Spotlight testing](https://www.conductor.build/docs/reference/scripts/spotlight-testing)是另一项功能：把一个工作区的 Git 跟踪更改同步到仓库根目录，复用固定端口、重型本地栈或构建缓存；关闭后恢复根目录状态。它一次测试一个工作区，且是单向同步。**不要把它写成 Spotlight 搜索导航。**

[官方 FAQ](https://www.conductor.build/docs/faq)解释：城市名提供稳定的工作区目录身份，侧栏以 PR 标题或分支名帮助识别任务。值得借鉴的是“稳定内部身份 + 易读任务名称”，而非直接复用城市命名。

[0.49.0 发行说明](https://www.conductor.build/changelog/0.49.0-conductor-allegro-gpt-5-5)报告了切换聊天保留滚动位置、过多终端标签横向滚动，以及暂时关闭终端 UI 后进程继续运行。这些是发行说明记录，未在本研究运行验证。

## 可独立复用的实现要点

以下均为原创建议，不是对 Conductor 隐藏实现的判断：

- 保留任务索引、对话、结果三个层级；窄屏时明确收起哪一层，避免全部压缩。
- 工具输出默认摘要，错误、文件变化和完整记录仍需一跳可达。
- 准备状态与对应动作相邻；颜色之外保留文字或图标。
- 切换会话时保留各自草稿、活动标签和滚动位置。
- 为模型、附件与发送建立清楚的主次关系，不让配置抢占输入空间。

### 建议验收

快速切换不丢草稿；命令面板 Escape 恢复原焦点；长标题可读全；收起边栏后有明确返回入口；展开工具记录不意外改变阅读位置；运行中与排队消息可区分。若加入动效，减少动态效果模式下也必须可用。
